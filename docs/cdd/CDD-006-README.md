# CDD-006 Assertion Engine

CDD-006 evaluates governed Subject–Predicate–Object propositions in one Context and produces immutable Assertion Records with Established, Candidate, or Rejected outcomes, Business Confidence, explanations, evidence, policy traceability, override, and external history.

The dedicated store refuses missing or mismatched EER/Semantic evidence. Canonical Assertion is removed from the generic Unit of Work registry so application code cannot bypass the cognitive sequence.

No Knowledge, Decision, Governance, AI reasoning, or CEO changes are included.
