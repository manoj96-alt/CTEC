# CR-001 — CDD Code Review Checklist

## Gate A — Repository and Architecture Review

- Required repository structure is present.
- Dependency direction and modular-monolith boundaries are preserved.
- No unauthorized entity, relationship, attribute, technology, or layer exists.
- Constitution, RFC, logical model, physical model, TAS, and current CDD are checked.

## Gate B — Code Quality Review

- Formatting, linting, static typing, tests, and builds pass.
- Configuration contains no hardcoded secrets.
- Logging, error handling, security, and dependency health are reviewed.
- CI runs the applicable quality gates.

## Gate C — Business Workflow Review

- Terminology matches the frozen business model.
- The workflow solves the assigned business problem and is intuitive to its intended users.
- No business behavior is invented beyond the assigned CDD.

## Freeze rule

A CDD may be frozen only when all applicable gates and the CDS-001 five-hat review pass. A gate that is not yet applicable must be recorded explicitly; it must not be silently marked as passed.
