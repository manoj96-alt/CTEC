# Architecture Release v1.8

Tenant-foundation architecture release (Increment 3A-0, RFC-015): ECOM Physical
Data Model v1.6 adds tenant ownership to `source_systems`, `source_objects`, and
`enterprise_entities`, and corrects an inherited bounded-extension layout defect
inside physical model v1.5 (duplicated CDD-012 runtime tables, misplaced CDD-013
audit table) without changing any runtime or audit behavior. Unchanged authorities
are inherited from v1.7. The Release Manifest is the integrity register for this
directory.
