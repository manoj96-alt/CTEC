# Architecture Baseline v1.1

Current architecture baseline. Authority and status are assigned by [`../../INDEX.md`](../../INDEX.md); presence in this directory alone does not make an artifact authoritative.

The ECOM Physical Data Model v1.3 source is restored and registered. [`RELEASE-MANIFEST-v1.1.xlsx`](RELEASE-MANIFEST-v1.1.xlsx) is the authoritative integrity register for every artifact in this baseline except the manifest itself; the Architecture Registry records the manifest checksum. `SHA256SUMS` is retained as a legacy partial checksum list and is not the release integrity authority.
