# Architecture Release v1.9

Gate D1 architecture release (RFC-016): ECOM Physical Data Model v1.7 adds
tenant ownership to `institutional_relationships` and re-authorizes
"Institutional Relationship" as a canonical Operational entity. This release
also publishes the PAD-001 Product-Internal Deterministic Capability Boundary
Clarification, establishing that deterministic, read-only, non-LLM
capabilities consuming only the frozen ontology and already-persisted
governed data — invoking none of ERM/SRM/ASM/KRM/DRM/GRM — fall outside
PAC-002's Cognitive Engine Question boundary. Unchanged authorities are
inherited from v1.8. The Release Manifest is the integrity register for this
directory.
